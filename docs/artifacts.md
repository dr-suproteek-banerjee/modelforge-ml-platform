# Model artifact storage

The API and worker use the same `ArtifactStore` interface. The default implementation is `LocalArtifacts` under `MF_ARTIFACT_ROOT` (the `artifacts` volume in Compose). Keys are generated by the application and are resolved inside that root.

| Key | Contents |
|---|---|
| `datasets/<id>.csv` | Original upload bytes |
| `models/<id>.zip` | Fitted `preprocess.skops` and an estimator in `estimator.skops`, native XGBoost `estimator.ubj`, or numeric PyTorch `estimator.npz` |
| `mlflow.db` | Default MLflow SQL tracking store in Compose |

Registry records store each bundle checksum, format version, Python and numerical-library versions, feature schema, class order, dataset version and digest, configuration, selected hyperparameters, train/holdout row counts and baseline drift summaries. Raw baseline samples stay in the service database. The worker reopens the artifact and runs a prediction before publishing the completed model. The API accepts CSV and structured prediction values. Artifact files originate only from the worker. Loading checks the stored SHA-256, enforces the recorded library versions, and uses a fixed skops type allowlist, native XGBoost model loading, or a pickle-disabled NumPy weights loader.

Restrict write access to the database and artifact directory to trusted service operators. Integrity hashes detect file changes relative to the trusted registry. Restore using the same locked environment. Library changes may require retraining and registering a fresh model version.

For backups, stop API and worker writes and capture PostgreSQL plus the artifact volume together. The MLflow database in the volume contains tracking metadata. Redis is broker state. Validate restored dataset digests and perform a prediction before resuming service.

An object-store implementation can replace `LocalArtifacts` through `put`, `get`, and `delete`. Keep stable keys, explicit integrity verification, atomic replacement semantics, and private access. Replication or crash recovery should include a reconciliation pass for unreferenced objects left by hard termination.
